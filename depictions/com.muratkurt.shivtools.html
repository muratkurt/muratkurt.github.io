shivtools

On-device tools for building tweaks.

An AI CLI running on the iPhone calls them; you don't have to. Any CLI, any model — Claude Code, Codex, Gemini, Grok, whatever runs in your terminal. The tools are plain shell scripts with fixed, readable output, so a model can call them and act on what comes back.

Tools

Environment

  • shiv-ortam — what this device is: jailbreak type, iOS, theos, frida, oldabi, node, every tool. First command of every session.
  • shiv-yol — one path, both namespaces (jbroot ↔ real root).

Discovery

  • shiv-sinif — classes and methods from the dyld cache, no frida needed. --tip reads a method's real signature from the running process; --sdk says whether it is declared in that class's SDK headers.
  • shiv-pencere — SpringBoard's windows and view tree: frames, safe area, transforms, model-vs-screen drift, interface orientation. Read-only.
  • shiv-ekran — the view tree of the app in front.
  • shiv-oku — every ObjC class inside a running app.
  • shiv-prefs-ornek — working examples pulled from Apple's own Preferences bundles.

Measurement

  • shiv-log — timestamped log: write, tail, summarise, plus a ready C snippet for the tweak side.
  • shiv-kare — screenshots as data: mark, then list only the frames taken after that mark.

Editing and packaging

  • shiv-sil — delete a line range with a dated backup, a diff and a syntax check.
  • shiv-kurulum — install the bundled instruction file into a project as CLAUDE.md and AGENTS.md.
  • shiv-cek — decrypt an App Store binary on the device.
  • shiv-frida-kur — check the frida setup; install only when you say so.

Included

  • SHIVTOOLS.md — the rules an agent follows: red lines, the measure → cause → fix → verify loop, tool reference.
  • TWEAK.md — recipes: build flows, ABI and caps, Preferences, hook patterns, discovery, namespaces.
  • shivfrida — frida client, statically linked, arm64e.

Both documents install to /usr/local/share/shivtools/.

Good to know

  • Every tool prints its usage with --help.
  • Missing dependencies are named: node is needed only by shiv-sinif, frida only by the tools that attach to a process.
  • The frida client is arm64e (A12 and newer). shiv-sinif, shiv-yol, shiv-log, shiv-sil, shiv-kurulum and shiv-ortam don't touch frida.
  • Nothing runs on its own. No daemon, no background process.

Requirements

  • iOS 15 or newer
  • rootless (Dopamine / Procursus) → the iphoneos-arm64 package
  • RootHide → the iphoneos-arm64e package
  • Optional: frida-server 16.x and nodejs

Built and used on iPhone 15 Pro (iOS 17.0.3, RootHide) and iPhone XS (iOS 16.1.1, Dopamine rootless).

If shiv is also installed, install shivtools after it: both own the same /usr/local/bin/shiv-* names. shiv-ortam and shiv-kurulum warn when the names point elsewhere.

Usage

Start here

shiv-ortam

It prints the jailbreak type, iOS version, theos, frida, oldabi, node and every tool. Run it first; don't assume any of them.

Set up a project

cd /var/mobile/Documents/MyTweak
shiv-kurulum

Writes CLAUDE.md and AGENTS.md from the bundled SHIVTOOLS.md — two names because different CLIs read different files. An existing copy is backed up with a timestamp first. shiv-kurulum --fark shows how a project's copy differs from the installed one.

Find a class or a method

shiv-sinif SBMediaController
shiv-sinif --tara Inventory
shiv-sinif --metod SBMediaController
shiv-sinif --metod SBMediaController --tip
shiv-sinif --metod UIAction --tip --sdk --desen handler

--tip prints the type encoding — return type and arguments — read from the live process. --sdk adds whether the selector is declared in the headers of that class, its superclasses or its protocols. Default target is SpringBoard; --pid N or --bid <bundle-id> picks another process.

Read the screen

shiv-pencere
shiv-pencere --izle 60
shiv-ekran com.apple.Preferences --ac

shiv-pencere dumps SpringBoard: window levels, the view tree, frames, safe= insets, tf= transforms, EKRAN: where the screen disagrees with your model, and the interface orientation.

--izle SECS records: a new numbered dump each time the layout changes, with a vibration so you know a moment was captured. Use it with a short numbered script for the person holding the phone. shiv-ekran does the same for the app in front; --ac brings it forward.

Measure behaviour

shiv-log parca        # C snippet to paste into the tweak
shiv-log yeni         # clear before a test round
shiv-log ozet         # count events
shiv-log son 60       # last lines

NSLog is not readable on these setups. Log to a file, then summarise — reading the raw file costs the agent its context.

Screenshots as data

shiv-kare isaret      # remember the newest frame
shiv-kare yeni        # paths of frames taken after that

Visual faults — flicker, one-frame redraws, wrong placement — never show up in a log. Only frames after the mark are listed; the camera roll is personal.

Edit safely

shiv-sil Tweak.x 420 875 --kuru   # preview
shiv-sil Tweak.x 420 875

Dated backup, deletes only that range, verifies the new line count, prints the diff, then checks for broken comments and unbalanced braces. Exit code 2 means the delete happened but a check failed.

Paths

  • Tools: /usr/local/bin/
  • Documents: /usr/local/share/shivtools/
  • Output: /var/mobile/tw/

On RootHide the shell lives in jbroot while system processes write to the real root. shiv-yol <path> translates between them; file tools that are not jbroot-aware need the real path.

Changelog

1.0.2

  • shiv-kare isaret writes through a temporary file, so a mark owned by another user no longer blocks it; an empty list now says so.
  • shiv-sil exits with 2 when a check fails.
  • shiv-ortam warns when the session runs inside a terminal app: a respring closes it too.
  • shiv-ekran --ac brings the app forward.
  • shiv-sinif --tip --bid wakes a suspended app before attaching.
  • shiv-pencere --izle writes a dump only when the layout really changes.
  • shiv-pencere reports interface orientation from the content size.
  • shiv-sinif --sdk is scoped to the class, its superclasses and its protocols, and matches the whole selector.

1.0.1

  • shiv-pencere view lines carry safe=, tf= and EKRAN:.
  • New: shiv-kare, shiv-sil.
  • shiv-sinif --tip --sdk.
  • Node candidates are tested by running them, not by their presence.

1.0.0

  • First release: 13 tools, shivfrida, SHIVTOOLS.md and TWEAK.md.
  • shiv-sinif --metod … --tip reads method signatures from the live process.
  • shiv-log, shiv-kurulum.
  • Works without shiv installed.
