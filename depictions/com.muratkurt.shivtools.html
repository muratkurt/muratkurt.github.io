Changelog

1.4.0

  • New: shiv-trace shows method calls live.
  • shiv-class --where and --live (no node needed).
  • Never reports "off" or "clean" when a tool is missing.
  • Fixes.

1.3.1

  • No longer needs Python: the Settings page works on every bootstrap.
  • Shows the iOS version without sw_vers.
  • Fixes.

1.3.0

  • Commands also have English names (shiv-env, shiv-class…).
  • Theos installs from Settings.
  • Settings shows available updates.
  • New: shiv-verify, shiv-back.

1.2.0

  • New: shiv-dugme presses the Action Button — single, double, long.
  • Settings shows whether the device has an Action Button.
  • Settings page no longer shows an old measurement after an update.

1.1.2

  • Security fix for the install helper. Please update.
  • Setup wizard now works on rootless.
  • Settings page in 9 languages.

1.1

  • Setup wizard in Settings → shivtools: shows what is missing and installs it — which packages, from which repo, with which command, and a live log.
  • New: shiv-kur checks and installs Node.js, frida, iOS MCP; shiv-theos-kur installs the right Theos for your device.
  • Refresh button on the Settings page.

1.0.4

  • Settings page redesigned: header card with version and a status summary, icons, tap-to-copy commands, credits with links, an About section.
  • The Settings page showed nothing on RootHide — the measurement was written where Settings could not see it. Fixed.
  • New: shiv-ornek — copy a working example tweak into your project. The development guide and three examples now install with the package.
  • Built for frida 17; the client is arm64 + arm64e. shiv-ortam --ajan-sina checks the whole frida chain.
  • New: shiv-mcp for the optional iOS MCP package.
  • Companion packages: Node.js 24 with npm, iOS MCP, frida 17 for RootHide.

1.0.2

  • shiv-kare isaret writes through a temporary file, so a mark owned by another user no longer blocks it; an empty list now says so.
  • shiv-sil exits with 2 when a check fails.
  • shiv-ortam warns when the session runs inside a terminal app: a respring closes it too.
  • shiv-ekran --ac brings the app forward.
  • shiv-sinif --tip --bid wakes a suspended app before attaching.
  • shiv-pencere --izle writes a dump only when the layout really changes.
  • shiv-pencere reports interface orientation from the content size.
  • shiv-sinif --sdk is scoped to the class, its superclasses and its protocols, and matches the whole selector.

1.0.1

  • shiv-pencere view lines carry safe=, tf= and EKRAN:.
  • New: shiv-kare, shiv-sil.
  • shiv-sinif --tip --sdk.
  • Node candidates are tested by running them, not by their presence.

1.0.0

  • First release: 13 tools, shivfrida, SHIVTOOLS.md and TWEAK.md.
  • shiv-sinif --metod … --tip reads method signatures from the live process.
  • shiv-log, shiv-kurulum.
  • Works without shiv installed.
