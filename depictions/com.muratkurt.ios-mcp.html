iOS MCP

An MCP server inside SpringBoard: an AI agent can take screenshots, read the accessibility tree and the live system log, tap, type, press the Action Button, open apps and more — 47 tools.

Based on witchan/ios-mcp 1.2.8, packaged for shivtools with safer defaults: it listens on 127.0.0.1 only, mcp-root comes without setuid, and installing a deb through it does not respring on its own.

Usage

Connect an agent

shiv-mcp durum          # installed, running, which mode
shiv-mcp baglan         # the claude mcp add line for this phone
shiv-mcp baglan --mac   # SSH tunnel + claude mcp add for a Mac

shiv-mcp comes with shivtools. Restart the CLI after adding the server.

Security

The server has no authentication. By default it only accepts connections from the phone itself.

  • shiv-mcp mod ag listens on the network — it asks first. Don't use it on public Wi-Fi.
  • From a Mac, prefer the SSH tunnel: login and encryption come for free.
  • shiv-mcp root-ac gives mcp-root its setuid bit. Only if you need root actions through the agent.

After installing

Respring once so SpringBoard loads the server. Settings → iOS MCP starts and stops it.
