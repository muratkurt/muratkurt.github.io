shiv

An AI assistant that runs in your terminal, on the device.

Talk to a model, let it run commands, keep the conversation across sessions. Bring your own API key — the provider is up to you.

Providers

  • Moonshot
  • DeepSeek
  • OpenAI
  • OpenRouter
  • Ollama (local)
  • Custom endpoint

Anything speaking the OpenAI /chat/completions format works. Claude is reachable through OpenRouter — Anthropic's own API uses a different shape and isn't supported directly.

What it does

Sessions

Every turn is saved. Pick up where you left off with /continue, or browse and search older conversations with /resume.

A restored session returns to the profile it was made with, so an OpenAI conversation doesn't quietly continue on another provider.

Profiles

Keep several providers side by side and switch between them. /profile decides who you connect to, /model decides what runs.

Two languages

Turkish and English. Chosen on first run, changeable any time with /lang. The reply language follows the interface language.

Input history

Arrow keys walk through previous prompts, Ctrl+R searches them. Ctrl+T opens the output panel.

Commands run on your device

With a permission prompt before anything executes.

Commands

Every command has both a Turkish and an English name.

/profile   /model     /settings  /resume
/continue  /lang      /name      /color
/new       /show      /geo       /help
/quit

Screenshots

Node.js is bundled. Install shiv and it runs — no runtime to add, no other repo, nothing to configure.

Versions before 1.2.0 needed Node.js separately. That package is still in this repo if you install an older build; it is imcynic's work.

Good to know

Don't run it as root. Files would end up owned by root and ~/.shiv could no longer be written by mobile.

Your data stays. Profiles, API keys, sessions and input history live in ~/.shiv. Removing the package leaves them alone — even on purge. Reinstall and you carry on where you stopped.

Your API key is yours. It is stored locally and sent only to the provider you chose.

Compatibility

Tested on iPhone 15 Pro, iOS 17.0.3, RootHide.

The rootless build has also been verified on a rootless device.

Other devices and iOS versions have not been tried. If something looks off, /geo prints everything needed to diagnose.

Changelog

1.2.0

Node.js is bundled now. Nothing else to install, on RootHide or rootless.

New

  • Sub-agents — the model can delegate. Large jobs get split into background sub-tasks that run in parallel: one searches files while another reads logs, and the results come back merged.
  • Performance presets — /performance. High, Balanced or Low power. Controls whether markdown is styled while streaming, how often the screen redraws, and how much history stays live.
  • Rewind — take the conversation back to an earlier point. Press Esc twice, pick a point, continue from there.
  • Background tasks — Ctrl+B sends a running job to the background and tells you when it finishes.
  • Startup hints — short tips appear on the right when you open the app, then fade on their own.

Changed

  • Speed. Typing, streaming and scrolling were rebuilt. Long sessions no longer slow down; the keyboard stays instant even after hundreds of messages.
  • Response time. The app was sending more than it needed to on every message. Replies start sooner now.
  • Look. New logo, consistent across the app, the icon and this page.

Fixed

  • Wrapped lines keep their indentation
  • Code blocks stay inside their border when wrapped
  • Arrow keys and Esc no longer drop keystrokes
  • Held backspace no longer jumps the cursor
  • Arrow keys no longer get stuck on commands in history
  • A crash on launch
  • Streaming slowing down on long replies

1.0.1

New — /context and /about, plus a detailed activity view on Ctrl+O.

Changed — /model, /profile and /lang are pickable lists now instead of typed arguments. /settings reorganised. Panels behave consistently with each other. Clearer message when you interrupt a reply.

Fixed — duplicate welcome card; model selection getting lost; Turkish strings showing up in the English interface; words breaking mid-word at the edge; session picker breaking on rotation; command names getting truncated.

Better — fewer screen refreshes, and opening or closing the keyboard no longer resizes the panels.

1.0.0

  • Rotation is smooth now. Turning the device reflows the screen to the new width and keeps your conversation with it.
  • No more flicker. Only the parts that actually changed get redrawn, while typing and while a reply streams in.
  • Landscape welcome card — logo on the left, shortcuts and working directory on the right.
  • Three new themes. Switch with /theme.
  • Command list is navigable. Walk it with the arrow keys, filter it as you type.
  • Working directories added with /add-dir are clearer in the panel.
  • Help panel reworked — two columns in landscape, full description of the selected command in portrait.

0.2.0

  • Verified on a rootless device — the rootless build is no longer untested
  • Node.js is now in this repo for both RootHide and rootless, so it installs alongside shiv
  • Language handling fixed
  • /geo output reworked
