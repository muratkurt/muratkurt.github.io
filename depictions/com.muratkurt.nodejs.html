Usage

Check it

node -v && npm -v && npx --version
node -e 'require("child_process").execSync("uname -m")'

The second line is the one that matters: it proves child_process works, not just node -v.

Good to know

  • Pure JavaScript packages install and run. Native add-ons (.node files) do not load.
  • A12 or newer. Older chips stop with SIGILL.
  • Run it from a login shell — the terminal app does this. Over a one-shot ssh host 'command', /usr/local/bin is not on PATH; use ssh host "zsh -lc 'node -v'".
  • Many workers at once can run out of address space. NODEIOS_V8_FLAGS=--jitless is the escape hatch.
  • shiv-sinif from shivtools is the tool that needs it; the rest of shivtools does not.
